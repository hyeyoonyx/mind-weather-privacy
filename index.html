내 안의 하늘 개인정보처리방침

시행일: 2026년 11월 24일

‘내 안의 하늘’은 개인 개발자 김혜윤이 운영하는 마음 기록 애플리케이션입니다. 사용자의 마음 기록과 개인정보를 소중히 여기며, 본 방침은 앱에서 처리하는 정보, 저장·삭제 방법 및 문의 방법을 안내합니다.

제1조. 처리하는 정보 및 목적

앱은 마음 기록을 작성·조회하고 통계를 표시하기 위해 사용자가 입력한 정보를 기기 안에서 처리합니다.

  • 날짜 및 시간: 기록 작성과 조회
  • 마음 날씨: 마음 상태 기록과 통계
  • 감정: 감정 기록과 분포 통계
  • 에너지 레벨: 에너지 변화 기록과 통계
  • 메모: 사용자가 작성한 생각과 감정의 보관
  • 내부 기록 ID 및 생성·수정 시각: 기록 식별과 관리

회원가입이나 로그인은 필요하지 않습니다. 사용자는 메모에 개인적이거나 민감한 내용을 직접 입력할 수 있습니다.

제2조. 정보 저장 및 외부 전송

마음 기록은 기기의 앱 저장소인 AsyncStorage에 저장됩니다. 확인된 앱 코드에서는 마음 기록을 개발자 서버 또는 분석·광고 서비스로 자동 전송하는 기능이 발견되지 않았으며, 앱 자체의 서버 동기화 기능은 없습니다.

정식 빌드의 모든 네트워크 통신을 실측으로 검증한 것은 아닙니다. 기기 운영체제의 백업과 사용자가 선택한 외부 공유 서비스에 따라 데이터나 파일의 사본이 기기 밖에 보관될 수 있습니다.

이 개인정보처리방침 페이지는 GitHub Pages에서 제공됩니다. 페이지를 방문하면 GitHub가 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요. 페이지 방문 시 앱의 마음 기록을 이 사이트에 전송하는 기능은 없습니다.

제3조. 보유 및 삭제

기록은 사용자가 앱에서 삭제하거나 앱 데이터를 삭제할 때까지 기기의 로컬 저장소에 보관됩니다. 사용자는 개별 기록을 조회·수정·삭제할 수 있습니다. 앱 삭제 또는 기기 초기화 시 기록이 사라질 수 있으며, 앱 자체의 기록 복원 기능은 제공되지 않습니다.

운영체제 백업 또는 별도로 보관한 PDF 사본은 앱에서 원본 기록을 삭제한 뒤에도 별도로 남을 수 있습니다.

제4조. PDF 내보내기

사용자가 요청하면 앱은 날짜·시간·날씨·감정·에너지·메모가 포함된 PDF를 기기 안에서 생성합니다. 이 과정에서 임시 캐시 파일이 남을 수 있으며, 앱은 PDF 파일에 별도의 암호화를 적용하지 않습니다.

앱은 iOS 공유 시트에 파일을 제공하며, 사용자가 저장 또는 전송 대상을 직접 선택합니다. 외부 공유 대상의 데이터 처리에는 해당 서비스의 정책이 적용될 수 있습니다. PDF는 읽기·보관용이며 앱으로 다시 가져오는 복원 파일이 아닙니다.

iOS에서는 PDF 공유가 종료되면 앱이 생성한 임시 PDF 파일의 삭제를 시도합니다. 오류 또는 앱의 강제 종료 등의 사유로 임시 파일이 남을 수 있습니다. 사용자가 별도로 저장하거나 공유한 PDF 사본은 앱에서 삭제하지 않습니다.

제5조. 제3자 제공 및 처리 위탁

앱에는 개발자 서버에 수집한 마음 기록을 제3자에게 판매하거나 제공하는 기능이 없습니다. 마음 기록을 외부 서버에 저장하거나 분석하도록 위탁하는 기능도 확인되지 않았습니다. 사용자가 직접 선택하는 파일 공유는 이와 구분되며, 선택한 대상에 따라 파일이 외부로 전달될 수 있습니다.

제6조. 안전성

앱은 로컬 저장을 사용하고 자체 외부 자동 동기화 기능을 제공하지 않아 전송을 최소화합니다. AsyncStorage는 앱 차원의 별도 암호화 저장소가 아닙니다. 기기 잠금과 운영체제 업데이트를 사용하고, 내보낸 PDF를 안전하게 보관하기를 권장합니다. 절대적인 무단 접근 방지나 데이터 복구를 보장하지 않습니다.

제7조. 이용자 권리 및 문의

사용자는 앱에서 자신의 기록을 조회·수정·삭제할 수 있으며, 개인정보에 관해 아래 이메일로 문의할 수 있습니다. 이메일 문의 시 발신자 이메일 주소와 문의 내용은 응대를 위해 처리되며 이메일 서비스 제공자를 통해 보관될 수 있습니다. 문의 내용의 보관·삭제에 관한 사항도 아래 연락처로 문의할 수 있습니다.
